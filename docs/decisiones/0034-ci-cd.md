# ADR-0034: CI/CD con GitHub Actions y promoción de la misma imagen

- **Estado:** Aceptada
- **Fecha:** 2026-10-21

## Contexto
Cada cambio debe validarse de forma automática, y cada despliegue debe poder repetirse y revertirse.

## Alternativas evaluadas
- Validar y desplegar a mano.
- Construir en el servidor en cada despliegue.
- Construir una sola vez en el CI y promover la misma imagen.

## Decisión
**CI en cada PR:**
- Corren en paralelo los trabajos de back, front, e2e y seguridad.
- El PR no se fusiona si alguno falla.

**CD:**
1. Al fusionar en `stage`, se construyen las imágenes, se publican en GHCR con la etiqueta del commit y se despliegan por SSH.
2. `main` despliega exactamente la misma imagen.
3. Para revertir, se vuelve a desplegar la etiqueta anterior.

**Complementos:**
- Los secretos se guardan en GitHub Environments.
- Dependabot y una plantilla de PR.

## Alternativas descartadas
- **Procesos manuales:** son propensos a errores y a pasos olvidados.
- **Construir en el servidor:** lo que llega a producción podría diferir de lo que se probó.

## Consecuencias
- Producción ejecuta exactamente lo que se probó en stage.
