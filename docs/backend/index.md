# Backend

La API es un monolito modular. Cada módulo (`auth`, `incidents`, `users`, `dashboard`, `system`) se divide en las capas Domain, Application, Infrastructure y Http. Cada módulo tiene su propia página con reglas, casos de uso y consultas.
